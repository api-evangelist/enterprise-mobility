# Enterprise Mobility

> Enterprise Mobility (legal parent Enterprise Holdings, Inc.; API licensor of record EAN Services, LLC) is the Clayton, Missouri parent of Enterprise Rent-A-Car, National Car Rental and Alamo Rent a Car, and the largest car rental provider in the world. It runs a real but partner-gated API program: the EHI API Marketplace at developer.ehi.com publishes marketing overviews for three API business lines — Rental, Replacement Rental and Commute — while the API catalog, specifications, guides and release notes all sit behind Azure AD B2C sign-in. No OpenAPI, no documented endpoint and no base URL for those business lines is published publicly. This file was generated by API Evangelist from public sources; Enterprise Mobility does not publish an llms.txt.

## Status

- Machine-readable contract: none published (no OpenAPI, Swagger, GraphQL, AsyncAPI or MCP server)
- Developer access: partner-only — "If you are an Enterprise employee or trusted Partner register and get access today"
- Identity layer: Azure AD B2C (tenant apimarketplaceprod), OpenID Connect, anonymously discoverable
- Production API host: https://api.ehi.com — Kong Gateway behind Imperva; no route is matched anonymously

## API business lines (public overviews)

- [EHI Rental APIs](https://developer.ehi.com/apis-overview/rental.html): Enterprise Rent-A-Car neighborhood and airport branch rental capabilities. Catalog gated.
- [EHI Replacement Rental APIs](https://developer.ehi.com/apis-overview/replacement-rental.html): ARMS and Entegral for insurers, collision repairers, dealerships and fleet maintenance — Communication, Lifecycle and Data capability groups. Catalog gated.
- [EHI Commute APIs](https://developer.ehi.com/apis-overview/commute.html): Commute with Enterprise vanpooling and rideshare-to-work programs. Catalog gated.

## Marketplace surface (published in the portal's own page source)

The EHI API Marketplace's own experience API is the one Enterprise surface whose endpoints are visible without an account. All calls are POST with JSON, an `Authorization: Bearer` access token and an `ehi-origin-identity` id_token.

- POST https://api.ehi.com/marketplace/experience/profile/{profileId}/retrieve-user-content
- POST https://api.ehi.com/marketplace/experience/profile/{profileId}/favorite-content
- POST https://api.ehi.com/marketplace/experience/profile/{profileId}/unfavorite-content
